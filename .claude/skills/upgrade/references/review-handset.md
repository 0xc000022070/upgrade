# The review handset and the other handsets

The review handset is the user's phone. It holds real data. Review surface only. `CLAUDE.local.md` names it, the other handsets `phone` knows, its adb address, and the install facts to check against.

- Push at every shipped feature automatically, without asking (user, 2026-09-03). The build number is the commit count at HEAD, so the feature commit is the release: no `pubspec.yaml` bump.
- `nix develop -c just deploy <handset>`, from the committed tree. Never `nix develop path:$PWD`: that hashes `build/` and `.dart_tool/` into the store and does not come back. `just deploy` bare takes every handset attached; a named one is dialled first. `just watch` in a pane keeps doing it at every commit: each new HEAD rings and asks there while it builds, an `n` shelves it, thirty seconds of silence installs it once the build is done. The build log goes to `build/deploy/build.log` and its tail is printed when it fails.
- `tool/deploy.sh` is the whole of it: it exports HEAD into `build/deploy/tree` (so another session's uncommitted work never ships), builds there, checks the apk's `versionCode` against the commit count and its signing cert against the debug keystore under `$ANDROID_USER_HOME`, reads each handset's installed `versionCode` and leaves alone any at or past HEAD, installs in place, and proves the install by `versionCode` and a moved `lastUpdateTime`. The verified apk stays at `build/deploy/upgrade-<name>-<code>-<sha>.apk`.
- Drive the device with the `phone` CLI, never raw adb; `dumpsys package dev.luisnquin.upgrade` is the one exception, the confirmation `phone` has no verb for. The handset's `firstInstallTime` must never move: a moved one means the package was replaced, not upgraded.
- Never `phone up` against the review handset: it launches the app, and the user opens it themselves. Never tap, type, `uninstall`, `pm clear`, or install a differently signed apk on it.
- Transport: `phone device list` must show the handset `attached/tcp`. `online` with a null serial is tailscale reachability, not adb. `phone device connect <handset>` first; when its sweep finds nothing, a plain `adb connect <adb address>` has worked.
- Record the push in memory with the lastUpdateTime.
