# Machines and tools

| name | address | role |
|---|---|---|
| nyx | 100.118.60.77 | this machine, runs Herdr, the app's first host once the user installs a key |
| rose | 100.73.224.47 | Apple silicon Mac, hosts `emulator-5554` (`pixel_7-api36`, arm64), parks release apks in `/tmp` |
| faraday | 100.127.25.101, adb `faraday:5555` | the user's phone, review only |

- The emulator on rose reaches nyx through the NAT. `100.64.0.253` is an unassigned CGNAT address, the unreachable probe.
- Keys for the app's hosts are installed by the user by hand. Never edit `authorized_keys` anywhere for evidence.
- Hot reload from nyx: `just run` forwards rose's adb server to `127.0.0.1:5038`.
- Herdr API answers on the unix socket `~/.config/herdr/sessions/hub/herdr.sock`; `herdr agent list` is the shape the app parses: `id` `cli:agent:list`, `result.type` `agent_list`, `result.agents[]`.
- Gradle speed comes from `~/.gradle/gradle.properties` generated by home-manager: daemon on, 14g heap, 1g metaspace. Release arm64 builds take about half a minute.
